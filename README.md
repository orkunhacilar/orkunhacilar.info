# orkunhacilar.info

Personal website built with HTML, CSS, and TypeScript.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Compile TypeScript:
```bash
npm run build
```

3. Watch for changes (optional):
```bash
npm run watch
```

4. Serve locally:
```bash
npm run serve
```

Then open your browser to the URL shown in the terminal.

## Structure

- `index.html` - Main HTML file
- `styles.css` - Styling
- `script.ts` - TypeScript source file
- `script.js` - Compiled JavaScript (generated from script.ts)

## Development

Edit the TypeScript file (`script.ts`) and run `npm run build` to compile it to JavaScript.
